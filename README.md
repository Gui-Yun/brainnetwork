# brainnetwork

Brainnetwork is a small toolkit for whole-brain neural activity analysis in mice.
It focuses on:
- data loading and preprocessing for `spikes` / `fluorescence`
- RR (responsive and reliable) neuron selection
- time-resolved decoding and Fisher Information
- correlation-based network construction and metrics
- publication-style visualization helpers

The project is mainly notebook-driven (`notebook/`), while reusable functions are in `src/brainnetwork`.

## Main Analysis Pipeline

1. Load raw files with `load_data`:
- `wholebrain_processed.mat` (spikes) or `wholebrain_output.mat` (fluorescence)
- trigger `.txt`
- stimulus `.csv`

2. Preprocess with `preprocess_spike_data` / `preprocess_data`:
- segment trials from triggers (default 50 frames per trial)
- compute dynamic baseline `dF/F` for fluorescence
- select RR neurons

3. Decoding and information analysis (`decoding.py`):
- `classify_by_timepoints`: per-timepoint SVM accuracy
- `FI_by_timepoints_v2`: per-timepoint Fisher Information (univariate/multivariate)
- `FI_by_neuron_count`: FI vs neuron count

4. Network analysis (`network.py`):
- `compute_correlation_matrix`
- `build_correlation_graph`
- `compute_network_metrics_by_class` (density, clustering, efficiency, modularity, betweenness, etc.)

5. Plotting (`visualization.py`):
- RR spatial distribution
- population average responses
- decoding accuracy curves
- Fisher Information curves
- correlation violin plots
- network metric bar plots

## Notebook Entry Points

## Minimal Example

```python
from brainnetwork import (
    load_data, preprocess_data, preprocess_spike_data,
    classify_by_timepoints, FI_by_timepoints_v2,
    compute_network_metrics_by_class
)

data_path = r"YOUR_DATA_DIR"

# spikes
neuron_data, neuron_pos, start_edges, stimulus_data = load_data(data_path, data_type="spikes")
segments_spi, labels_spi, neuron_pos_spi = preprocess_spike_data(
    neuron_data, neuron_pos, start_edges, stimulus_data, extract_rr=True
)

# fluorescence
neuron_data_flo, neuron_pos_flo, start_edges_flo, stimulus_data_flo = load_data(
    data_path, data_type="fluorescence"
)
segments_flo, labels_flo, neuron_pos_flo = preprocess_data(
    neuron_data_flo, neuron_pos_flo, start_edges_flo, stimulus_data_flo
)

# decoding
accuracies, time_points, accuracy_std, n_folds = classify_by_timepoints(segments_flo, labels_flo)
fisher_mv, time_points_fi = FI_by_timepoints_v2(
    segments_flo, labels_flo, mode="multivariate", reduction="none"
)

# network
nx_result = compute_network_metrics_by_class(
    segments_spi, labels_spi, neuron_pos_spi, do_bootstrap=False
)
```
